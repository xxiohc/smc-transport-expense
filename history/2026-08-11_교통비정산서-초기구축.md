## 11차 개편 (2026-08-12) — 테스트 사용자 주입 + 임시저장 기능

### 사용자 요청

1. 계약관리시스템에 등록된 실제 직원 + 다양한 유종/배기량 차량을 교통비정산서에 등록
2. 작성 중단 후 재개할 수 있는 임시저장 기능

### 구현 항목

#### 1. 테스트 사용자 주입 (16명)

Supabase `contract-db` 버킷에서 실제 직원 명단을 조회하여 `te_users` 주입.
차량 유종/배기량을 다양하게 분산 배정:

| 연료 | 배기량 | 대표 사용자 |
|------|--------|------------|
| 휘발유 | 1000cc 미만 | 이준경, 박수현 |
| 휘발유 | 1500cc 이하 | 박미숙, 조윤서 |
| 휘발유 | 1500cc 초과 | 김도영, 나정민, 구연정 |
| 경유 | 1500cc 이하 | 심규옥, 김종국, 정미선, 장성웅 |
| LPG | 1500cc 이하 | 손정균, 권민, 권기범, 윤종부 |

연비 계산 검증:
- 휘발유 1000cc 미만: 9 km/L ✅
- 휘발유 1500cc 이하: 8 km/L ✅
- 휘발유 1500cc 초과: 7 km/L ✅
- 경유: 7 km/L ✅
- LPG: 5 km/L ✅

#### 2. 임시저장 기능

**저장 키**: `te_draft_{userId}` (사용자별 분리, 7일 만료)

**저장 항목**: tripMode, currentStep, trips, tripIdSeq, hasToll, totalTollAmount, 폼 입력값 전체

**임시저장 버튼**: Step 2·3·4·5 하단 step-actions 중앙에 노란 버튼 추가
- 저장 시 2초간 초록 "저장됨" 상태로 시각 피드백

**임시저장 배너**: 로그인 후 `checkDraft()` 실행
- 저장본이 있으면 헤더 직하 오렌지 배너 표시
- "이어서 작성하기" (오렌지 버튼) → `restoreDraft()` 실행
- "새로 시작" (회색 버튼) → `discardDraft()` 후 Step 1

**draft restore 동작**:
- tripMode 상태 복원 (자차/택시 UI 분기)
- 폼 필드 값 복원 (차량번호·연료·배기량·유류단가 등)
- 이동내역 trips 배열 복원 → `renderTrips()` 재실행
- 하이패스/주차비 상태 복원
- 저장 당시 단계로 `gotoStep()` 이동

**z-index 스택**: `draft-banner`는 sticky 없음(fixed header 직하에 흐름 배치),
`wizard-bar`는 배너 높이만큼 `style.top` 동적 조정 (80 + bh px)

**resetWizard()** → `clearDraft()` 호출로 기존 임시저장 삭제

### 검증

- 자차 선택 → Step 2 진행 → 임시저장 버튼 클릭 → 저장됨 피드백 ✅
- 새 정산서 → 로그인 화면 → 재로그인 → 오렌지 배너 표시 ✅
- "이어서 작성하기" → Step 2 복원, 폼 값(차량번호·연료·배기량) 정상 복원 ✅
- wizard-bar top 동적 조정으로 배너 가려짐 없음 ✅
- 7일 만료 로직 확인 (Date.now() - savedAt > 7일) ✅
