- CDN: Pretendard, xlsx-js-style

### 3. 주요 기능
- **헤더 UI**: 13번 프로젝트(검사장비비교시뮬레이터)와 동일한 패턴
- **기본 정보**: 이름·차량명·번호·연료·배기량·정산기간 → LocalStorage 자동저장
- **유류단가**: 오피넷 직접 링크 + 수동 입력 → km당 단가 자동표시
  - 오피넷 CORS 이슈로 직접 fetch 불가 → 수동입력+링크 방식 채택
- **이동 내역 테이블**: 구간 추가/삭제, 이동수단(자차↔택시) 토글
  - 출발지/도착지: 카카오 REST API 장소 검색 모달
  - 거리: Kakao Mobility Directions API 우선, 실패 시 Haversine×1.3 fallback
  - 삼성의료원(127.0849986, 37.4882579) 기본 출발지
- **계산**: `Math.round(거리 × 단가 / 연비 / 10) * 10` (10원 반올림)
- **합계 카드**: 건수·총거리·유류비·정산신청액 실시간 업데이트
- **엑셀 내보내기**: xlsx-js-style로 정산서 형식 다운로드
- **인쇄**: CSS @media print 적용
- **API 키**: `995bceb54093798d160d753693a9c98e` (09번 프로젝트에서 재사용)
