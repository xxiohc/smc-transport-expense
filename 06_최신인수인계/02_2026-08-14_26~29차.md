## 27차 — TF 테스트 계정 모드 + 관리자 테이블 너비 (`89c8cb0`)

### 작업 목표
TF(테스트 팀)가 계속 반복 테스트할 수 있도록 PIN/차량 변경이 저장되지 않는 테스트 계정 모드 구현.
관리자 패널에서 버튼이 잘리는 레이아웃 버그 수정.

### 수행 내용

**TF 테스트 계정:**
- DB 스키마: `account.is_test: boolean` 필드 추가
- `server.js`: `handleInitialPin`, `handleChangePin`, `handleUpdateMyCar` — `is_test` 계정은 writeDb 건너뜀
- `sanitize()`: `pin_is_default = is_test ? false : (hash === hashPin("0000"))` — 테스트 계정은 항상 PIN 변경 화면 미표시
- `handleToggleTest(id)`: `is_test` 토글, writeDb
- `index.html`: `toggleTest(id)` 함수, `테스트ON/OFF` 버튼, `테스트` 배지 추가

**관리자 테이블 너비:**
- `.admin-content` max-width: `860px → 1160px`
- `user-table td:last-child`: `min-width: 340px` 추가

### 산출물
- `server.js`, `public/index.html` 수정

## 28차 — 유류단가 색상 (오피넷 조회 전후 구분) (`0ec56c8`)

### 작업 목표
오피넷에서 가격을 불러오기 전에는 유류단가·km단가 숫자를 회색으로 표시해 "아직 조회되지 않은 값"임을 시각적으로 표시.

### 수행 내용
- `let fuelConfirmed = false` 전역 플래그 추가
- `setFuelColors()` 함수: `fuelConfirmed` 여부에 따라 색상 전환
  - `false` → `var(--muted)` (회색)
  - `true` → `var(--ink)` / `var(--primary)` (정상색)
- `fetchOpinet()` 성공 시: `fuelConfirmed = true`
- `f_fuelPrice` 수동 입력 시: `fuelConfirmed = true`
- `useSavedCar()`, `step2Next()`: `fuelConfirmed = false` (step 3 진입 초기화)
- 임시저장 복원: `fuelConfirmed = true` (저장된 값은 확인된 것으로 처리)

### 산출물
- `public/index.html` 수정

## 29차 — 유류 변경 시 연비 즉시 반영 교정 (`31c9633`)

### 작업 목표
step 3 유류단가 화면에서 유류 종류(휘발유/경유/LPG)를 변경했을 때 연비와 km단가가 즉시 갱신되지 않던 버그 수정.

### 버그 원인
- `fuelTypeSelect`(step 3 오피넷 조회 드롭다운)에 `onchange` 핸들러 없음
- `getEfficiency()`가 step 3의 `fuelTypeSelect`를 무시하고 step 2의 `f_fuel`만 참조
- 결과: LPG 선택해도 휘발유 연비로 계산, 수식에 7km/L 표시 (LPG는 5km/L이어야 함)

### 수행 내용
- `OPINET_FUEL` 역매핑 상수 추가: `{ B027: '휘발유', D047: '경유', K015: 'LPG' }`
- `getActiveEfficiency()` 함수 추가: `fuelTypeSelect` 코드 → 연료명 변환 → 연비 반환
- `getEfficiency()`: step 2 effDisplay 전용으로 유지 (f_fuel 참조)
- `getActiveEfficiency()` 적용 범위: `updateFuelDisplay`, `calcFuelCost`, `buildPreview`, `downloadExcel`
- `fuelTypeSelect`: `onchange="updateFuelDisplay()"` 추가

### 산출물
- `public/index.html` 수정
